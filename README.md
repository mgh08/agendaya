# AgendaYa – El Corte Caribe

Prototipo web de agendamiento de citas para la barbería El Corte Caribe (barrio El Prado, Barranquilla).
Proyecto aplicado de Gerencia en Proyectos Informáticos – CUN, grupo 54447 (2026).

**Ver el prototipo:** https://mgh08.github.io/agendaya/

## Módulos

- **Reservar cita:** el cliente elige servicio, barbero (o "cualquier barbero"), día y hora libre. Las horas ocupadas no se pueden reservar, lo que evita los cruces de horario.
- **Agenda del día:** citas por barbero, registro de asistencia y recordatorio por WhatsApp.
- **Administrar:** servicios con duración y precio, barberos y horario de atención.

## Tecnología

HTML, CSS y JavaScript en un solo archivo, sin servidor. Los datos se guardan en el navegador (localStorage) y vienen con citas de ejemplo; el botón "Restablecer datos de ejemplo" las recarga con la fecha del día.
